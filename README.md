# Yogeshvar Reddy Kallam — Developer Portfolio

Personal portfolio website for **Yogeshvar Reddy Kallam**, a Computer Science engineer passionate about AI, Machine Learning, and innovative technologies.

🌐 **Live site:** [yogeshvarreddykallam.github.io/blog](https://yogeshvarreddykallam.github.io/blog)

## About

This is a static single-page portfolio showcasing projects, skills, and background. Built with vanilla HTML, CSS, and JavaScript — no frameworks, fully client-side.

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom styles (`styles.css`) + responsive layout
- **JavaScript** — smooth scrolling, interactions (`main.js`)
- **Swiper.js** — carousel/slider component
- **Unicons** — icon library

## Structure

```
.
├── index.html          # Main page
├── styles.css          # All styles
├── main.js             # Interactive behaviour
├── swiper-bundle.min.css
├── swiper-bundle.min.js
├── bg.png              # Background image
├── CNAME               # Custom domain config
└── .vscode/
    └── launch.json
```

## Local Development

No build step required — just open `index.html` in a browser, or serve with any static server:

```bash
npx serve .
# or
python3 -m http.server 8080
```

## Deployment

Hosted on **GitHub Pages**. Any push to `main` automatically updates the live site.
