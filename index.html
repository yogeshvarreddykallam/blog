// projects

Selected projects

A mix of systems work, applied ML, and research-driven builds. Most have public repos.

Virtual Memory Manager & Userspace Paging Engine

CLinuxPOSIX signalsGDB

Userspace VMM simulating OS demand paging on limited frames. Intercepts SIGSEGV via sigaction + SA_SIGINFO, extracts faulting addresses from ucontext_t, and toggles mprotect() protections. FIFO and Third-Chance (clock-with-dirty-bit) page replacement to minimize disk I/O.

Multithreaded OS Scheduler & Sync Engine

CPthreadsLinuxGDB

Custom uniprocessor scheduler with FCFS, preemptive SRTF, and a 5-level MLFQ (5–25ms quanta). Built thread-safe counting semaphores from scratch using pthread_mutex and condition variables — fully passive-wait, no spin-locks.

Custom Heap Allocator

CLinuxMemory Mgmt

Buddy + Slab allocators on a custom heap, with power-of-two partitioning, recursive merge, and kernel-style Slab Descriptor Tables for small-object reuse. my_malloc / my_free APIs with embedded metadata, user-aligned pointers.

Masked Time-Series Transformers for Motion Forecasting

PythonPyTorchBERTSSL

6-layer Transformer encoder pre-trained on 3,883h of unlabeled IMU data with 15% masked patches, fine-tuned for forecasting + HAR. 25.5% MAE reduction, 72.6% accuracy across 6 activities, F1 0.91 on Sleep.

Flight Delay Prediction with Fused Weather Data

PythonXGBoostscikit-learnSQL

Predicted U.S. domestic delays by fusing 725K flight records with NOAA hourly weather using leakage-free merge_asof. Cyclical sin/cos encoding for temporal features, traffic-count proxies. Scenario sim: 3.2× delay multiplier in severe winter weather.

ModiCross: Two-Stage Document Ranking

PythonTransformersCrossEncoder

Modified CrossEncoder with a novel scoring mechanism (logits + cosine similarity) on 96K query-doc pairs. Hard negative mining + combined loss → +0.26 nDCG@10 and 50%+ ranking precision lift over baseline.

Faulty Science Question Analysis

PythonBERTRoBERTaNLP

Fine-tuned BERT and RoBERTa on a curated multi-discipline science-question dataset to detect flawed reasoning. Up to 91% accuracy, with analysis of model weaknesses on ambiguity and subtle logical errors.

Skin Cancer Detection via Image Segmentation

PythonSVMCNNHOG

One-Class SVM + CNN on 1K+ dermoscopy images. HOG-based feature extraction cut false positives by 30%, and tuned classifiers improved early-detection capability by 20% on 500+ test images.

Travel Management System

JavaNode.jsMongoDBHTML/CSS

Full-stack travel platform with admin dashboard, secure payments, and AI-driven trip recommendations. Real-time itinerary management, booking history, and customer inquiry support.
